# Gtheory4LLM 0.0.7 release

The source archive includes three real publicly archived LLM annotation panels
(eight outcome sets, fifteen codings) and the installed vignette. The
accompanying 31-page PDF is the package reference manual. Research manuscripts
and private working archives are excluded. Package code is GPL-3; the annotation
data retain CC BY 4.0.

The archive was built with R 4.5.3 from the source commit in `manifest.json`,
which records archive and manual SHA-256 checksums. Independent installation and
the archived smoke test passed against that commit. This bundle was assembled
locally; the workflows in `.github/workflows/` record what each environment
checked for the commit it ran on, and are the reference for cross-platform
results rather than this file.

The manual is generated by `scripts/build_manual.R`, which refuses to emit a
manual containing overfull boxes. It has not been reviewed page by page.

These files do not establish CRAN acceptance. See the GitHub release for
submission status.

Verify archive integrity, source correspondence, and installation with:

```sh
python3 scripts/run_validation.py --scope artifact
```

See `scripts/VALIDATION.md` for source and artifact validation details.
